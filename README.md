# Library Management System

## Project Overview

A Library Management System developed using Microsoft Access as part of a university group project. The system is designed to organize library data and simplify basic library management operations.

## Features

- Book record management.
- Author information management.
- Member information management.
- Librarian information management.
- Borrowing record management.
- Fine record management.
- Database tables and relationships to organize library data.
- Forms for entering, viewing, and managing library information, where implemented.

## Technologies Used

- Microsoft Access
- Relational Database Design

## My Contribution

I contributed to most of the project's development, including designing and working on the database structure and implementing the main library management functionality. Some parts, including reports, queries, and a few additional features, were not completed by me.

## How to Use

1. Download the project files from this repository.
2. Open the Microsoft Access database file using Microsoft Access.
3. Use the available forms and database objects to explore the implemented functionality.
